## 🛒 Superstore Sales Analytics Project

A complete data analytics project using Python, MySQL, and Power BI
to clean, store, query, and visualize retail sales data.

---

## 🛠️ Tools & Technologies
- **Python** (Pandas, Jupyter Notebook / Google Colab)
- **MySQL** (Database, Queries, Views)
- **Power BI** (Interactive Dashboard)

---

## 📁 Project Structure

| File | Description |
|---|---|
| `superstore.ipynb` | Data cleaning & preprocessing |
| `cleaned_sales_data_2.csv` | Final cleaned dataset |
| `Sales_Analytics__sql_Project.sql` | Database & table creation |
| `Total_Sales.sql` | Total revenue query |
| `Sales_by_Region.sql` | Revenue by region |
| `Top_10_Products.sql` | Top 10 products by revenue |
| `Monthly_Sales_Trend.sql` | Monthly revenue trend |
| `Avg_Delivery_Time.sql` | Average delivery days |
| `sales_summary.sql` | Regional revenue view |
| `salesproject_powerbi.pdf` | Power BI dashboard |

---

## 📊 Power BI Dashboard
- KPI Cards — Total Sales, Total Orders, Avg Delivery Days
- Sales by Region, Year, Product, and Segment
- Filters for Region, Category, Year, and Date range

---

## 📌 Key Insights
- West region had the highest revenue
- Consumer segment accounted for 67% of sales
- Identified top 10 products driving maximum revenue
- Tracked yearly sales growth from 2015 to 2018

---

## 🚀 How to Run
1. Run `superstore.ipynb` to generate the cleaned CSV
2. Run `Sales_Analytics__sql_Project.sql` to create the database
3. Import `cleaned_sales_data_2.csv` into the `sales_data` table
4. Run any `.sql` file to explore insights
5. Open Power BI and connect to the dataset to view the dashboard
